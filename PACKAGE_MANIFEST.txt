AEDT Multi-PC Toolkit 2026 R1 - GUI NOEXE

給同事的操作入口：
1. 解壓縮全部檔案到 C:\AnsysWork\MpiToolkit。
2. 雙擊 START_HERE.html 閱讀圖文說明。
3. 雙擊 Run-MpiToolkit-GUI.bat；只有按「① 完整修復（管理員）」時才會要求系統管理員權限。

本版新增：
- NODEB 專用的 Setup-NODEB-OpenSSH.cmd：雙擊一次完成本機設定；最後由 NODEA 實際驗證金鑰登入。
- GUI「⑤ 連線修復」。
- 統一兩台的 tempdirectory 為 C:\AnsysWork\AedtTemp。
- 自動備份 default.cfg。
- 啟動並驗證 Electromagnetics RSM 與 Intel Hydra。
- 依 Ansys Help 設定 RSM MPI 必要的 ANSYS_EM_EXEC_DIR。
- 修復後驗證本機及對端 TCP 32958。
- 固定 AnsoftCOM TCP 55000-55499 與 Intel MPI TCP 55500-55999。
- 自動偵測 Intel Hydra 服務埠，建立工具專用的網域／私人防火牆允許規則。
- 所有防火牆規則只允許 LocalSubnet，不會關閉 Windows 防火牆。
- GUI 加入 Intel MPI 原生帳密註冊與對端驗證；工具不接收密碼，也不把密碼放入命令列或報告。
- GUI 加入「③ 雙機快速測試」；一次驗證 MPI 帳密、RSM、Hydra、兩節點 hostname 與既有 Ansys 程序。
- GUI 內容會隨視窗大小延展；縮小時提供分頁捲軸。
